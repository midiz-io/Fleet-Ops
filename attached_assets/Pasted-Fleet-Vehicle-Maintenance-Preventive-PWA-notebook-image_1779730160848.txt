Fleet Vehicle Maintenance & Preventive PWA ඔබේ notebook එකේ images තුනේ තියෙන සියලු concepts එකතු කරලා, mobile-first dark-theme Progressive Web App එකක් හදනවා. Drivers field එකේ phone එකෙන් use කරන්න සුදුසු, Manager office එකේ ඉඳන් fleet එක monitor කරන්න සුදුසු විදිහට. ## Roles & Login - **Phone + 4-digit PIN** login - **Fleet Manager** — vehicles/drivers add, schedule, approve repairs, see all dashboards - **Driver** — own assigned vehicles only, daily checklist, meter/fuel entry, repair requests ## Main Modules ### 1. Vehicle Profile Each vehicle stores: Vehicle No (eg `GAI 1005`), Model (eg `Bolero`), benchmark KMPL (eg `14`), Purchase Date, License expiry, Insurance expiry, SIM/GPS number, assigned Driver. Document expiry දින approach වෙද්දී dashboard එකේ red badge. ### 2. Driver Profile Name, Phone, PIN, License No & expiry, assigned vehicle(s), incentive points (good checklists + on-time service = points). ### 3. Daily Driver Login & Checklist Driver login → today's vehicle pick → checklist: - Meter reading **with photo upload** (camera capture) - Oil check (OK / Low / Needs change) - Tyres, lights, brakes quick check - Submit → timestamp + GPS optional ### 4. Fuel Log & KMPL Tracking Driver enters: liters added, amount paid, odometer. App auto-calculates KMPL vs benchmark (Bolero 14). Below benchmark → flag for manager review. Per-vehicle mileage chart. ### 5. Weekly Maintenance Schedule Manager sets vehicle's weekly plan (Mon/Tue/Wed/Thu/Fri) — eg "Mon: Service, Wed: Oil". Drivers see "Today's vehicle work" reminders. Preventive maintenance reminders based on meter (eg every 5000 km service). ### 6. Repair Requests Driver creates repair entry (description, parts needed, optional photo) → status `Pending`. Manager opens Repair List → **Confirm / Reject** with notes. Approved repairs add to cost log. ### 7. Cost Dashboard Three cost categories per vehicle: **Fuel Cost, Service Cost, Other Cost** → combined **Running Cost**. Two views: - **Each Vehicle Summary** — single vehicle, monthly trend - **All Vehicles Summary** — fleet totals, comparison chart ### 8. QR Scanner Quick-Access Each vehicle gets a unique QR (printable from vehicle profile). Driver scans → instantly opens that vehicle's checklist / fuel entry. ### 9. Preventive Maintenance Meeting Log Simple notes module — record meeting date, attendees (Mr. Shimal, Saman, etc.), guidelines discussed, suggestions. Acts as fleet knowledge base. ## Navigation (Mobile bottom-bar) - Home (today's tasks + alerts) - Vehicles - Fuel/Checklist - Repairs - Dashboard *(manager only)* - Profile / QR Scan ## PWA Features - Installable on Android/iOS home screen (manifest + icons) - Offline-friendly shell (cached UI) - Camera access for meter photos & QR scanning - Push-style in-app reminders for service due dates ## Design - **Dark theme** (deep navy / charcoal background, cyan + amber accents) — easy on eyes, good for night driving / field use - Large tap targets, big numbers for meter/fuel inputs - Status colors: green=OK, amber=due soon, red=overdue/failed ## Technical Notes - TanStack Start + Lovable Cloud (Supabase: phone auth, Postgres, Storage for photos, RLS by role via `user_roles` table) - Tables: `profiles`, `user_roles`, `vehicles`, `drivers`, `assignments`, `checklists`, `fuel_logs`, `maintenance_schedule`, `repairs`, `costs`, `meeting_notes` - Roles enforced server-side (`app_role` enum: `manager`, `driver`) — no client-side privilege checks - Photo uploads → Supabase Storage bucket - Recharts for cost/KMPL charts - PWA: simple manifest + icons (no service worker — Lovable preview safe) ## Out of scope (v1 — can add later) - Live GPS map tracking from SIM (just stores SIM number for now) - Route Manager / Task Manager assignment workflow - Push notifications (will use in-app alerts) - EV charging station finder ඔබ approve කළ පසු මම මේක build කරන්නම්.
